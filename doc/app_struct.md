# Архитектура сервера автопровижининга

## Модель данных

### Таблица Configurations (создаем)
- MAC-адрес (уникальный ключ)
- Производитель
- Модель
- IP-адрес
- User-Agent
- ID экстеншена (ссылка на Extensions)
- SIP-сервер (хост)
- SIP-порт
- Транспорт (UDP/TCP/TLS)
- Признак полноты конфигурации
- Признак изменения (для перезагрузки телефона)
- Временные метки (создание, обновление, последний визит)

### Таблица Extensions (уже есть в Isabel)
- Номер
- Пароль
- Отображаемое имя
- Временные метки

Обе таблицы находятся в одной БД с PBX.

## Репозитории

### ConfigurationRepository
- Получение конфигурации по MAC-адресу
- Создание новой конфигурации
- Обновление конфигурации
- Получение списка всех конфигураций
- Получение конфигурации по ID экстеншена

### ExtensionRepository
- Получение списка всех экстеншенов
- Получение экстеншена по ID
- Получение экстеншена по номеру

## Конфигуратор

Загружается из файла при старте приложения:
- Адрес SIP-сервера (по умолчанию для всех телефонов)
- Порт SIP-сервера
- Тип транспорта (UDP/TCP/TLS)
- Параметры подключения к БД
- Настройки кэширования

## Сервисы

### DeviceValidatorService
- Проверка, является ли устройство телефоном
- Определение производителя и модели
- Кеширование результатов проверок

### ConfigurationService
- Управление жизненным циклом конфигураций
- Создание конфигурации при первом обращении телефона
- Обновление конфигурации
- Проверка полноты конфигурации
- Управление признаком изменения

### ExtensionService
- Получение списка доступных экстеншенов
- Назначение экстеншена конфигурации
- Проверка доступности экстеншена

### ConfigGeneratorFactory
- Фабрика генераторов конфигурационных файлов
- Выбор генератора по производителю

### ConfigGenerators (по одному на вендора)
- YealinkConfigGenerator
- CiscoConfigGenerator
- GrandstreamConfigGenerator

Каждый генератор:
- Принимает конфигурацию и экстеншен
- Возвращает содержимое конфигурационного файла в формате вендора
- Учитывает признак необходимости перезагрузки

## Хендлеры (эндпоинты)

### Провижининг (для телефонов)
**GET /{MAC}.cfg**
- Извлечение MAC из имени файла
- Валидация устройства (DeviceValidatorService)
- Поиск конфигурации (ConfigurationRepository)
- Если конфигурации нет — создание записи, возврат 404
- Если конфигурация неполная — возврат 404
- Если конфигурация полная — генерация файла (ConfigGeneratorFactory), возврат 200
- Если был признак изменения — сброс признака

### Админ-интерфейс
**GET /admin/phones**
- Получение списка всех конфигураций (ConfigurationRepository)
- Отображение: MAC, производитель, модель, IP, номер, имя, статус

**GET /admin/configurations/{id}/edit**
- Получение конфигурации по ID
- Получение списка доступных экстеншенов (ExtensionService)
- Отображение формы редактирования

**POST /admin/configurations/{id}/assign-extension**
- Назначение экстеншена конфигурации (ConfigurationService)
- Проверка доступности экстеншена
- Установка признака полноты конфигурации
- Установка признака изменения

**POST /admin/configurations/{id}/update-server**
- Обновление параметров SIP-сервера (хост, порт, транспорт)
- Установка признака изменения

## Поток данных

### Первое обращение телефона
1. Телефон запрашивает `{MAC}.cfg`
2. DeviceValidatorService проверяет устройство
3. ConfigurationRepository ищет конфигурацию — не находит
4. ConfigurationService создает запись с `is_complete = false`
5. Возврат 404

### Повторное обращение (до настройки)
1. Телефон запрашивает `{MAC}.cfg`
2. ConfigurationRepository находит конфигурацию
3. Проверка `is_complete` — false
4. Возврат 404

### После назначения номера админом
1. Админ назначает экстеншен через веб-интерфейс
2. ConfigurationService устанавливает `extension_id`, `is_complete = true`, `has_changed = true`

### Обращение после настройки
1. Телефон запрашивает `{MAC}.cfg`
2. ConfigurationRepository находит конфигурацию
3. Проверка `is_complete` — true
4. ExtensionRepository получает данные экстеншена
5. ConfigGeneratorFactory генерирует файл
6. Если `has_changed = true` — добавляет команду перезагрузки, сбрасывает признак
7. Возврат 200 с содержимым файла
